# Open-source research notes

These projects are reference points, not dependencies. No source code, datasets, fonts, or assets from them are vendored here.

| Project | Useful reference | License recorded during review |
|---|---|---|
| [Hanzi Writer](https://github.com/chanind/hanzi-writer) | Character stroke-order playback and interaction | MIT |
| [p5.brush](https://github.com/acamposuribe/p5.brush) | Expressive brush primitives for p5.js | MIT |
| [perfect-freehand](https://github.com/steveruizok/perfect-freehand) | Pressure-aware freehand stroke geometry | MIT |
| [Paper.js](https://github.com/paperjs/paper.js) | Vector path manipulation and timing | Check the repository before adopting |
| [Aquarelle](https://github.com/Ramotion/aquarelle) | Watercolor-mask animation as a product effect | MIT |
| [Pillow 11.3.0](https://github.com/python-pillow/Pillow/tree/11.3.0) | Maintainer-only raster export for the social preview | MIT-CMU |

Research snapshot: 2026-08-20. Licenses and project status can change; verify the current repository before adopting code.

The distinctive contribution of InkBrush Motion is the delivery contract around these broad techniques: native 9:16 composition, exact knowledge text, static approval, brush-to-ink causality, evidence frames, and truthful readiness states.
